# Hanzo Studio Current Specifications

This directory contains the current version of Hanzo Studio's manifest files and API definitions.

## Files

- `api.py` - Python interface for Hanzo Studio's backend API
- `api.ts` - TypeScript interface for Hanzo Studio's frontend API
- `node_def.py` - How to define a custom node in Python
- `node_def.json` - How a custom node is saved in a workflow json.
- `pyproject.toml` - Manifest file for custom node pack.
